# [ARRAY] # [HASH_TABLE] # [DECISION_TREE] # [PRIORITY_QUEUE]

End-to-End Computer Vision & 4-Stage DSA Pipeline

1
Stage 1 — Fixed-Size 8-Element Feature Array (O(H × W))

Extracts Green Leaf Ratio, Brown Lesion Ratio, Yellow Chlorosis Ratio, Canny Edge Density, Shannon Entropy, Dark Necrotic Ratio, Saturation Spread, and Lab Colour Contrast using OpenCV.

2
Stage 2 — 31-Bucket Hash Table with Separate Chaining (O(1) Avg)

Uses a Polynomial Rolling Hash (prime base 31, 31 buckets) to map "crop|pest" directly to its agronomic record and candidate treatments.

3
Stage 3 — Binary Decision Tree Severity Classifier (O(H))

Evaluates affected leaf area % against thresholds: < 15% Low, 15–35% Moderate, and > 35% Severe.

4
Stage 4 — Manual Binary Max-Heap Priority Queue (O(T log T))

Scores and extracts candidate treatments from highest to lowest composite priority (Efficacy + PHI Safety + Cost per Acre in INR).
